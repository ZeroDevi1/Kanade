# 和声色彩（音乐分析）

音乐分析页的「和声色彩」卡片把识别出的和弦放到五度圆盘上，并画出和声进行的新鲜感随时间的变化。
实现见 `internal/score/color.go`（计算）与 `page_score_color.go`（界面），只用已有的和弦识别结果，不需要额外模型。

## 来源与边界

思路参考华萃康「色彩和声」：和声进行的新鲜感来自和弦在五度圈上方向的变化（色彩）与紧张度的变化。
B 站「色彩和声工作室」在此基础上提出了极坐标向量模型与「新鲜感 = 色差 + 张力差」的量化思路
（专栏 cv21690345）。Kanade **只借鉴这一思想**：度量方式是独立选取的，不使用华萃康的紧张度分级表，
也不涉及该工作室软件中的和弦温度、张力分级、调式库等未公开内容。

## 度量

- **位置**：和弦音级集合的第 5 个离散傅里叶系数 f₅（Quinn 2006；Amiot 2016《Music Through Fourier Space》）。
  每个音按五度圈位置（pc × 7 mod 12，每格 30°）取单位向量求平均：方向是和弦在五度圈上的整体方向，
  模长（0–1）是各音在五度圈上的集中程度。纯五度 0.97、挂留 0.91、大小三和弦 0.64、七和弦 0.48、减三 0.33、增三 0。
  集中程度高的和弦更协和、色彩更鲜明；靠近圆心的张力大、方向感弱。
- **朝向**：整体旋转到调号主三和弦朝正上方；顺时针（右）为升号方向（明亮），逆时针（左）为降号方向（暗淡）。
  因此外圈的主音名本身不在正上方，而在主三和弦方向的左侧约 45°。
- **色差** = 相邻两和弦位置的距离（0–2）；**张力差** = 模长之差的绝对值（0–1）；**新鲜感** = 色差 + 张力差。
- **曲线**：每小节内各次换和弦的新鲜感之和，主线取 4 小节滑动平均（约一个乐句）。

## 已知局限

- f₅ 不区分「大三和弦 X」与「根音高大二度的小三和弦」（如 Db 与 Ebm，两者只差一个音），二者在圆盘上重合，
  合并显示为「Db / Ebm」，相互之间的色差为 0。
- 结果受和弦识别词汇限制：默认的「完整和弦」（BTC 神经网络）识别 14 种性质（含六和弦、各类七和弦、增减和弦与挂留），
  模板匹配的「大小三和弦」张力差几乎为 0、新鲜感全部来自色差。add9、四度叠置等和弦仍识别不出来；
  转位只影响低音，不改变色彩点的位置。
- 和弦识别的错误（例如人声干扰下把某拍识别成调外和弦）会直接表现为新鲜感的尖峰；分析前先分离伴奏可减少这类误差。
